# AI agent guidance

This repository owns CLI commands and RN/Godot templates. Taro packages and its
project template live in htyf-taro; migration skills live in htyf-skills.

For full, partial, or incremental HTYF project migration, install and use the
htyf-migration skill from https://github.com/htyf-mp-community/htyf-skills.
Its rules cover feature parity, native dependencies, template selection,
capsule and safe-area layout, and migration acceptance.
